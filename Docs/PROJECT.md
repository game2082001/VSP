# 專案說明

你目前正在參與 VSP（Video Surveillance Platform）專案。

本專案採用：

- MVVM
- Repository Pattern
- Driver Framework
- Lite Clean Architecture

所有工作都必須遵守專案規範。

# 開始修改前

請先確認：

- 是否理解需求。
- 是否理解目前 Architecture。
- 是否與 Spec 衝突。

若有衝突：

請停止修改並提出原因。

不得自行修改 Architecture。

# 修改限制

不得：

- Do not modify MainWindow.
- Do not modify Architecture.
- Do not modify unrelated files.
- Do not create another Device Management View.
- Do not delete legacy files.
- Do not run Git commands.

若需要修改超過 8 個檔案，

請先提出原因。
