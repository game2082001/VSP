# AI Development Workflow

Workflow index for how AI agents execute a Task in VSP. This document describes the workflow only — governing rules live in the linked documents below, not here.

## Workflow

```text
Task
  ↓
Analysis
  ↓
Architecture Review
  ↓
Spec
  ↓
Planning
  ↓
Approval
  ↓
Implementation
  ↓
Technical Review
  ↓
Architecture Review
  ↓
Definition of Done
  ↓
Commit
```
