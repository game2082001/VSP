## 1. What RC1 is

"RC1" is a label introduced by this report for the current, complete codebase state: every v1.0-required capability (Epic-013 through Epic-018) individually implemented, Manually Validated at its own acceptance, and Accepted/Frozen by the Product Owner, on top of the pre-existing baseline (Epic-001 through Epic-012, per `Docs/V1.0_CUSTOMER_RELEASE_DEFINITION.md` §2.1). It is now also a committed state and a produced build artifact — see §8. It is this report's name for "the build that Internal Validation's remaining gates, and then Pilot, will be run against."
