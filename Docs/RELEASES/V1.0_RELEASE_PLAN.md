## 5. What this plan deliberately does not do

- Does not declare Internal Validation, Pilot, or GA complete — each remains gated on its own checklist's actual evidence.
- Does not invent a new deployment mechanism (no installer, no auto-update, no CI/CD) — Epic-013's xcopy/self-contained-publish approach is the only one in scope for v1.0, per its own accepted, disclosed-out-of-scope list.
- Does not commit any code or tag any release — that remains the Product Owner's action.
- Does not start Epic-019 or any new feature work — explicitly out of scope for this plan.

## 6. Roles

- **AI Agent**: prepares checklists/reports, executes non-invasive verification (builds, automated tests, clean-machine checks it can perform, documentation), never commits/pushes, never declares acceptance or GA.
- **Product Owner**: decides pilot parameters, performs or delegates the combined manual validation and security review, commits code, gives formal GA approval.
