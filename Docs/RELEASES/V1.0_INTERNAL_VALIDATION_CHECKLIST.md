## Combined Manual Validation script (superseded, kept for record only)

This script was prepared for gate 3 in case a new combined session was required. It was **not executed** — the Product Owner instead approved gate 3 based on the existing Epic-017/Epic-018 individual validations (see gate 3's evidence above). Retained here only as a record of what was prepared, not as an outstanding action item:

1. Launch; confirm "VSP - Login" appears.
2. Log in as `operator` — confirm exactly four nav items (no Settings, therefore no Backup/Restore reachable at all).
3. Confirm Live View loads and Start Recording is disabled.
4. Log out (confirm the confirmation prompt), log back in as `admin`.
5. Confirm Settings is visible; open it; confirm the Backup/Restore section is present.
6. Change one Setting (e.g. Theme) and Save — confirm it persists and the log file records nothing unexpected.
7. Perform a Backup to a chosen file — confirm the file opens correctly in a SQLite tool.
8. Add or delete a camera, then Restore from that backup — confirm the destructive-action confirmation, the success message, and clean termination.
9. Relaunch manually — confirm the restored data, confirm a `vsp.pre-restore.*.db` file exists, confirm the day's log file has entries for both the Setting change and the Backup/Restore actions from this same session.
