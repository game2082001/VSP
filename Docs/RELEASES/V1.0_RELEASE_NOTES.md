## What's new in v1.0

### Admin/Operator accounts
VSP now requires signing in. Two roles are supported: **Admin** (full access) and **Operator** (day-to-day monitoring — read-only camera details, no Settings/Backup/Restore access, cannot start or stop recording). Passwords are stored using industry-standard PBKDF2-HMACSHA256 hashing with a per-user random salt — never in plain text.

### Database Backup / Restore
Admins can now back up VSP's camera database to a file of their choosing, and restore from a previously saved backup. Restoring is protected by a confirmation step, validates the backup file before touching anything, and automatically keeps a safety copy of the current database in case a restore ever needs to be undone. VSP restarts automatically after a successful restore.

### Settings
A Settings screen (Admin only) now lets you configure: Recording Path, Retention Days, Language selection, and Theme (Light/Dark/System).

### Application logging
VSP now keeps a daily log file for diagnostic purposes, stored under your local application data folder, with 30 days of retention.

### Improved error handling
Several situations that previously failed silently (database issues, camera connection problems, playback errors) are now logged and, where appropriate, shown to you with a reference ID you can share with support.

### Simple installation
VSP is distributed as a self-contained folder — no separate installer, no .NET runtime to install first. Copy it to the target machine and run it.

## Also included (carried forward from earlier releases)

Camera Management (add/edit/delete/search/filter/batch operations), automatic camera Discovery (ONVIF, RTSP probe, network scan), Live View, continuous Recording, Playback (play/pause/stop/seek), and a Dashboard overview.

## Known limitations in this release

- **Operator accounts must be created manually.** There's no in-app way to create an Operator account yet — only the default Admin account is created automatically. Reach out to support if you need an Operator account set up.
- **No self-service password change.** Password changes today only happen when required (the very first Admin login). Rotating a password afterward requires support assistance.
- **Language setting doesn't yet translate the interface.** The setting is saved, but VSP's on-screen text is English-only in this release.
- **Theme applies mainly to the Settings screen today.** Other screens will receive full Light/Dark theming in a future release.
- **Backup files are not encrypted.** A backup file contains the same information as your live database (including saved camera credentials) — store backup files as carefully as you would the original.
- **Recording is Continuous-only.** Scheduled or motion-triggered recording is not yet available.
- **No account lockout or automatic session timeout.**

None of the above are defects — each is a deliberate scope decision for this release, tracked for a future version.

## System requirements

- Windows 10/11, x64.
- No .NET runtime pre-installation required (self-contained deployment).
- Local storage for recordings and the application database.
